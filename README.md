# ФІНАЛ — кінематографічна сцена

Автоматична фінальна сцена (~2:50) для запуску з PowerPoint. Працює локально, без інтернету і без сервера.

## Запуск

1. Відкрийте `index.html` у Chrome або Edge (з PowerPoint — гіперпосиланням на цей файл).
2. Клацніть будь-де на сцені (або Enter / пробіл). Це єдина дія глядача: клік вмикає звук, повний екран і timeline.

Після кліку браузер на кілька секунд показує власну підказку «Esc — вийти з повноекранного режиму». Щоб її не було, натисніть F11 ще до кліку і поставте `requestFullscreen: false` у `js/config.js`.

## Що де лежить

```
final/
├── index.html          розмітка сцени
├── css/final.css       вигляд шарів, зірок, тексту
├── js/config.js        ← усе, що ви редагуєте: тексти, таймінги, позиції, шляхи
├── js/final.js         animation engine (чіпати не потрібно)
└── assets/
    ├── background/     sky.png — фон без великих зірок
    ├── then-now/       childhood.jpg, then-now.mp4, modern.jpg
    ├── memories/       memory-1…6.png — фото вже разом зі своїми рамками
    ├── fonts/          Cormorant Garamond (ліцензія OFL)
    └── audio/          сюди покласти музику
```

## Хід сцени

| Час | Акт | Що відбувається |
|---|---|---|
| 0:00 | Старт | сцена оживає |
| 0:05 | I | дитяче фото, відео «тоді → тепер» |
| 0:23 | II | сучасне фото розчиняється у світлі |
| 0:31 | III | 6 спогадів, галерея |
| 0:58 | IV | 12 зірок і 12 слів |
| 1:32 | V | слова зникають, зірки по черзі летять у подарунок (остання — «КОЛІР») |
| 1:46 | VI | привітання: 5 блоків по черзі |
| 2:36 | VII | «З Днем народження, / Аня!», одна світлова нитка малює навколо серце, пауза, fade to black (2:51) |

Акти I–IV задані абсолютними секундами (`…At`). Усе від Act V задано **тривалостями** і саме стає одразу за останнім словом.

## Що редагувати (усе в `js/config.js`)

| Що | Де |
|---|---|
| Музика | зараз `assets/audio/i-lived.mp3`; щоб замінити — інший файл у ту саму папку і шлях в `audio.src` |
| Привітання | список `greeting`: у кожного блоку `text`, свій час читання `hold` і (за бажанням) `fontSize` |
| Фінальний титр (два рядки) | `texts.birthdayLine`, `texts.birthdayName`; кеглі — `layout.birthday` |
| Серце: пауза перед ниткою і швидкість малювання | `timing.heartPause`, `timing.heartDrawDuration` |
| Серце: розмір і місце | `layout.birthday` (`x`, `y`, `width`, `height`; пропорції 11 : 8) |
| Скільки стоїть готова арка зі слів | `timing.wishHoldDuration` |
| Політ зірок у подарунок | `timing.starCollectionDuration` (один політ), `timing.starCollectionGap` (інтервал) |
| Поява/зникнення блоків привітання | `timing.greetingTransitionDuration` |
| Час читання блоку за замовчуванням | `timing.greetingBlockDuration` (якщо в блоці немає `hold`) |
| Скільки стоїть готова композиція з серцем | `timing.birthdayTitleHoldDuration` |
| Затемнення | `timing.finalFadeDuration` |
| Підгонка перших актів під музику | значення з `At` у блоці `timing` |

Перенос рядка в тексті — `\n`. Якщо рядок виявиться ширшим за сцену, кегль зменшиться автоматично.

Музика грає на повній гучності під час затемнення і плавно стихає вже на чорному екрані за `audio.fadeOut` секунд (`0` — трек дограє до свого кінця).

## Підгонка таймінгу

- `index.html?debug=1` — таймкод, назва акту, момент чорного екрана, попередження, якщо акти в конфігу наїхали один на одного. Клавіша **P** — пауза.
- `index.html?t=90` — старт одразу з 90-ї секунди (можна разом: `?debug=1&t=90`). Зручно для фінальної частини: `?t=90` — арка зі слів, `?t=105` — привітання, `?t=155` — титр і серце.

Годинник фіналу — сама музика: анімація не може розійтися зі звуком. Без музики (або якщо файл не завантажився) фінал іде за системним таймером.

## Якщо міняєте assets

- **Відео.** `childhood.jpg` збігається з першим кадром відео, `modern.jpg` — з останнім (вирівняні з точністю до пікселя). Якщо перегенеруєте відео, ці два фото треба підготувати заново, інакше підміни стануть помітними.
- **Фото спогадів.** Замініть файл у `assets/memories/` (PNG із прозорим фоном, рамка всередині файлу). Розмір і місце в галереї — у `memories` в конфігу.
- **Фон.** Має бути 16:9. Якщо подарунок зсунувся — оновіть `layout.giftLight`.

## Запасні сценарії, які вже закладені

- Відео не завантажилось або зависло → лишається дитяче фото, у свій момент воно переходить у сучасне.
- Музика не завантажилась → фінал іде без звуку за таймером.
- Якесь фото не завантажилось → воно просто не показується, решта йде далі.
- Помилка в одній дії не зупиняє timeline; повторний клік нічого не запускає вдруге.
- Вкладка побувала у фоні → після повернення сцена одразу стає у правильний момент.
